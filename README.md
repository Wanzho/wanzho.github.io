# wanzho.github.io

The root page of https://wanzho.github.io/: links to MCD2 Crossover and wasdmod, and the site name and icon Google shows for every page under this address.

Plain HTML, no build step. The two project sites live in their own repositories:

- MCD2 Crossover: `gh-pages` branch of [Wanzho/mcd2-crossover](https://github.com/Wanzho/mcd2-crossover) → https://wanzho.github.io/mcd2-crossover/
- wasdmod: [Wanzho/wasd](https://github.com/Wanzho/wasd) → https://wasdmod.com/

`sitemap.xml` lists all three pages; `googlec83721d81dd78788.html` verifies the site in Google Search Console.
